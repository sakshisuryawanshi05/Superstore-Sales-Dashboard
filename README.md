# 📊 Superstore Sales Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze Superstore sales performance across regions, customer segments, product categories, payment methods, and shipping modes.

## Key Metrics
- Total Sales: $1.57M
- Total Profit: $175.26K

## Features
- Regional Sales Analysis
- Profit Analysis by Category and Sub-Category
- Customer Segment Analysis
- Payment Mode Analysis
- Shipping Mode Analysis
- Interactive Filters and KPIs

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights
- Consumer segment contributes the highest sales.
- Technology category generates the highest profit.
- Standard Class is the most preferred shipping mode.
- COD is the most frequently used payment method.
